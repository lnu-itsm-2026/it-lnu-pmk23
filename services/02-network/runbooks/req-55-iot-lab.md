# Мережа для IoT-лабораторії (REQ #55)
- Призначення: Ізольована мережа (VLAN) для ~30 IoT-пристроїв кафедри, створена згідно із запитом #55.
- Правила доступу: Дозволено тільки доступ до інтернету. Зв'язок із внутрішніми сервісами ЛНУ заблоковано на рівні маршрутизації (заходи безпеки).
- CAB / RFC: Зміни погоджено та впроваджено в межах Issue #55.
