# RFC-031: Розгляд встановлення плагіна Moodle для тестування

## 1. Запит

- Пов'язаний тікет: #31
- Сервіс: Навчання (Moodle)
- Тип: запланована зміна
- Ініціатор: завідувач кафедри
- Статус: запропоновано, очікує уточнення та погодження
- Власник зміни: Change Manager

## 2. Мета

Оцінити можливість встановлення плагіна для створення тестів, автоматичної перевірки відповідей і перегляду результатів студентів.

## 3. Передумови

Кафедра повідомила про потребу в плагіні до модульного контролю. Офіційне посилання, точна назва плагіна та підтверджена дата проведення контролю мають бути уточнені.

## 4. Оцінка ризиків

1. Несумісність із версією Moodle.
2. Порушення роботи тестів або журналу оцінок.
3. Ризики безпеки та конфіденційності даних.
4. Недостатньо часу для тестування до потрібної дати.

## 5. План реалізації

1. Отримати назву плагіна, офіційне джерело та функціональні вимоги.
2. Перевірити сумісність, безпеку, права доступу та вимоги до даних.
3. Провести тестування в ізольованому середовищі, якщо воно доступне.
4. Отримати погодження відповідального власника сервісу та інших необхідних учасників.
5. Лише після погодження визначити вікно встановлення й повідомити користувача.

## 6. План відкату

Якщо після встановлення виникнуть проблеми із сумісністю, тестуванням, оцінками або даними, припинити зміну та відновити попередню конфігурацію за перевіреною процедурою. Перед зміною потрібно підтвердити, що відкат технічно можливий.

## 7. Критерії прийняття

- Плагін перевірено на сумісність і безпеку.
- Основні сценарії тестування пройшли перевірку.
- Не порушено роботу наявного оцінювання.
- Власник сервісу погодив зміну.
- Підготовлено та перевірено план відкату.

## 8. Поточне рішення

**Очікує уточнення та погодження.** Це RFC не є дозволом на встановлення. До отримання необхідних даних і погодження встановлення в робочому середовищі не виконується.

## 9. Результат розгляду

Заповнити після фактичного рішення CAB/відповідальних осіб. Не позначати зміну погодженою або виконаною без підтвердження.
